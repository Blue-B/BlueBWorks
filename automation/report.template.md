상태: not_started / blocked / failed / verified 중 실제 상태
프로젝트: 실제 이름과 projects/<slug> 경로

## 만든 것과 선정 이유

대상 사용자, 반복되는 문제, 핵심 사용 흐름. 검토한 후보와 선택 이유를 간략히 적는다. 내부 사고 과정 대신 확인 가능한 결정 근거만 남긴다.

## 기존 대안과 차이

검증한 대안 두 개 이상의 링크와 기능 차이. 유일하다거나 무조건 더 낫다고 과장하지 않는다.

## 조사 근거

출처 링크, 발표일(확인된 경우), 확인일. 수요·수익·가격이 미확인이면 표시한다.

## 실제 구현

동작하는 핵심 기능과 주요 변경 파일. 예제 데이터와 실제 연동을 구분한다.

## 검증 증거

코드 커밋: 실제 URL
Pull Request: 실제 URL
GitHub Actions: 실제 실행 URL과 결과
확인한 입력·상호작용·오류 처리:
실행하지 못한 검사:

문서·구조 검사와 제품 기능 테스트를 구분한다. 성공을 확인하기 전에는 verified라고 적지 않는다. 아직 생성되지 않은 링크는 미생성으로 표시한다.

## 실행 방법

필수 환경, 정확한 명령, 체험 순서. 실제 배포된 경우에만 공개 데모 URL을 기재한다.

## 한계와 다음 검증

미완성 기능, 비용·개인정보 주의사항, 검증되지 않은 수익화 가설. 실패·승인 대기라면 막힌 단계와 필요한 조치를 적는다.
