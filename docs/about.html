소개

개발 도구와 AI 서비스를 직접 써 보고, 공식 문서로 확인한 사용법과 조건, 한계를 적는 사이트입니다.

다루는 내용

개발 도구와 오픈소스, AI 제품의 새 기능과 사용 방법을 소개합니다. 비용과 지원 범위도 함께 다루며, 각 글에 발표일과 원문 링크를 남깁니다.

운영자

BlueBWorks는 개발자 Blue-B가 운영하는 개인 사이트입니다. 사이트 코드와 글 원본은 GitHub 저장소에 공개되어 있습니다. 연락은 문의 페이지의 이메일이나 GitHub 이슈로 받습니다.

운영 원칙

  • 직접 써 보고 쓴다: 소개하는 도구와 서비스는 직접 설치하거나 실행해 보고, 그때 본 화면을 글에 싣습니다.
  • 공식 문서로 확인한다: 가격, 한도, 지원 범위 같은 사실은 기업 공식 발표와 문서, 원 저장소로 확인하고 각 글에 출처를 남깁니다.
  • 한계도 함께 적는다: 되지 않는 것, 조건이 붙는 것, 한국에서 쓸 수 없는 것을 함께 적습니다.
  • 바뀌면 고친다: 내용이 바뀌거나 오류가 확인되면 글을 고치고 정정 기록을 남깁니다.

사이트 상태

  • 운영 형태: 개인 프로젝트
  • 호스팅: GitHub Pages의 정적 파일
