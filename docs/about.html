HOW IT WORKS

많이 모으는 대신, 확인할 만한 것만 남겨.

AI 소식은 빠른 만큼 같은 내용이 반복되거나 과장되기 쉬워. 이 사이트는 공식 발표와 원 저장소를 먼저 확인하고, 실제 사용 가치가 있는 변화만 정리하는 걸 기준으로 해.

무엇을 보나

OpenAI, Anthropic, Google/DeepMind, GitHub 같은 공식 발표를 우선 보고, GitHub와 Hugging Face의 새 오픈소스, Hacker News 등 개발자 커뮤니티 반응을 보조로 확인해. X는 원 개발자나 공식 계정 확인용으로만 써.

무엇을 안 올리나

단순 홍보, 근거 없는 벤치마크, 출처를 찾기 어려운 소문, 이미 다룬 내용의 반복은 건너뛰어. 중요한 새 소식이 없는 회차에는 글을 억지로 만들지 않아.

글에서 확인할 수 있는 것

각 글에는 발표 날짜와 확인 시각, 공식 출처를 남겨. 요약보다 원문이 필요한 경우 바로 공식 페이지로 갈 수 있게 연결해.
