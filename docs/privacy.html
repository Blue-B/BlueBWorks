개인정보 처리방침

계정과 자체 분석 도구는 두지 않습니다. 사이트를 읽을 때 실제로 일어나는 외부 요청을 적었습니다.

수집하는 것

이 사이트는 회원 가입, 댓글, 로그인 기능이 없습니다. 운영자는 이름, 이메일 주소 같은 개인정보를 직접 받거나 보관하지 않습니다. 자체 방문 분석 도구도 두지 않으며, 사이트 자체 코드는 쿠키를 설정하지 않습니다.

브라우저에 남는 값

동작 줄이기 설정을 기억하기 위해 브라우저의 로컬 저장소에 값 하나를 저장합니다. 이 값은 서버로 전송되지 않고 브라우저에서 지우면 사라집니다.

외부 요청

  • 호스팅: GitHub Pages가 접속 기록을 처리합니다. 처리 방식은 GitHub의 정책을 따릅니다.
  • 영상: 검증된 공식 영상이 있는 글에서 재생을 누를 때만 YouTube no-cookie 도메인으로 요청을 보냅니다.
  • X 게시물: 공식 X 게시물을 인용한 글을 열 때만 X(platform.twitter.com)의 임베드 스크립트를 불러옵니다. 추적 안 함(data-dnt) 설정을 켜 두며, X의 정책이 적용됩니다. 스크립트가 차단돼도 인용문과 원문 링크는 그대로 보입니다.
  • 출처 링크: 각 글의 출처와 자료 링크는 외부 사이트로 이동하며, 그 사이트의 정책이 적용됩니다.

문의

개인정보에 관한 문의, 정정 요청은 GitHub 이슈로 보내 주세요. 이슈는 공개되므로 이름, 연락처 같은 개인정보는 적지 마세요. 자세한 방법은 문의 페이지에 있습니다.

바뀌면

수집 항목이나 외부 요청이 바뀌면 이 페이지를 먼저 고칩니다. 이 페이지의 변경 내용은 저장소의 공개 기록으로 확인할 수 있습니다.
