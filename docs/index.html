Chrome 154의 반응형 iframe, postMessage 없이 콘텐츠 높이에 맞춘다

Chrome 154가 iframe의 높이·너비를 임베드된 문서의 실제 콘텐츠 크기에 맞춰 계산하는 `frame-sizing`을 정식 채널에 넣었다. 부모 페이지가 자식 문서의 높이를 재서 `postMessage()`로 전달하던 코드를 줄일 수 있지만, 임베드 문서의 명시적 opt-in과 동적 변경 시 `requestResize()` 호출, 기존 브라우저용 fallback은 여전히 필요하다.

mold 3.0: C++을 버리고 Rust로 다시 쓴 초고속 링커

고속 링커 mold가 3.0에서 구현 언어를 C++에서 Rust로 전면 교체했다. 사용자 입장에서는 2.42.1과 같은 명령행 옵션·지원 아키텍처·출력을 유지하는 드롭인 교체를 목표로 하지만, 직접 빌드하는 사람에게는 CMake에서 Cargo로 바뀌고 Rust 1.95 이상이 필요해졌다.

Cloudflare Traces로 WAF부터 원본 서버까지 한 요청을 이어서 본다

Cloudflare가 실제 운영 요청이 보안 규칙, 변환, 캐시, Workers, 원본 서버를 어떻게 지나갔는지 한 타임라인에서 보여 주는 Cloudflare Traces를 오픈 베타로 공개했다. 별도 계측 없이 Cloudflare 구간을 자동으로 기록하고, 필요한 요청만 더 촘촘하게 수집하거나 OpenTelemetry로 외부 도구와 연결할 수 있다.
