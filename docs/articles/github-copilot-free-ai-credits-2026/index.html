깃허브 코파일럿 무료 사용량, 6월부터 AI 크레딧으로 센다

깃허브 코파일럿 무료(Copilot Free)는 카드 등록 없이 깃허브 계정만 있으면 바로 쓸 수 있는 요금제입니다. 웹에서는 github.com/copilot 주소로 들어가면 채팅 창이 바로 열리고, VS Code 같은 편집기나 터미널용 코파일럿 CLI에서도 같은 계정으로 이어서 쓸 수 있습니다.

예전에는 무료 플랜 한도를 채팅 몇 번, 코드 완성 몇 번처럼 횟수로 안내했습니다. 2026년 6월 1일부터는 모든 코파일럿 요금제가 GitHub AI Credits라는 단위로 바뀌었습니다. 깃허브는 4월 27일 블로그 글에서 이 변경을 예고했고, 6월 1일 공지에서 모든 플랜이 쓴 AI 크레딧만큼 계산된다고 밝혔습니다. 크레딧은 입력 토큰, 출력 토큰, 캐시 토큰을 모델별 API 요금으로 바꾼 값이고 1크레딧은 0.01달러로 칩니다.

헷갈리는 건 무료 플랜의 숫자입니다. 요금제 페이지에는 Pro 15달러, Pro+ 70달러, Max 200달러처럼 유료 플랜마다 한 달 크레딧 금액이 적혀 있지만 무료 칸에는 Limited chat and agent usage라는 문장 하나뿐입니다. 공식 문서도 Copilot Free와 Copilot Student에 AI 크레딧 허용량이 있다고만 쓰고 숫자는 적지 않았습니다. 이 숫자는 로그인한 뒤 웹 채팅 화면 안에서 볼 수 있습니다.

무료 플랜에서 고를 수 있는 모델은 Auto 하나

웹 채팅 입력창 오른쪽 아래에 모델 버튼이 있습니다. 무료 계정으로 눌러 보면 목록 맨 위에 Upgrade to access more models and higher limits라는 안내가 붙고, 실제로 고를 수 있는 항목은 Auto 하나입니다. 그 아래로 GPT-6 Luna, Claude Haiku 5.5, Kimi K3, Claude Sonnet 5.5 같은 이름이 줄줄이 보이지만 전부 회색으로 잠겨 있고, 목록 아래쪽 Claude Opus 5.5나 GPT-6.1 Sol 옆에는 Pro+ 표시까지 붙어 있습니다.

공식 문서 설명도 같습니다. 무료와 학생 플랜은 자동 모델 선택으로만 모델을 쓴다고 적혀 있습니다. 요금제 페이지 무료 칸에는 Haiku 4.5, GPT-5 mini 등에 접근한다는 문구가 아직 남아 있는데, 웹 채팅 메뉴에서 이 이름들을 직접 고를 수는 없었습니다.

Auto가 어떤 모델로 답했는지는 답변 아래 다시 시도 버튼에서 알 수 있습니다. 이번에 보낸 두 질문은 모두 Retry with Auto (GPT-6 Luna)로 표시됐습니다. GPT-6 Luna는 모델 목록에서 Fast and cost-efficient, 그러니까 빠르고 저렴한 쪽 묶음에 들어 있는 모델입니다. Auto가 고르는 모델은 질문이나 시점에 따라 달라질 수 있습니다. 내가 모델을 정해 두고 쓰고 싶다면 유료 플랜으로 올려야 합니다.

코파일럿 남은 AI 크레딧 확인하는 곳

남은 양은 입력창 오른쪽 아래, 보내기 버튼 바로 왼쪽에 있는 동그란 게이지 아이콘에서 봅니다. 마우스를 올리면 View token usage라고 뜨고, 누르면 작은 창이 열립니다. 맨 위 Included credits 칸에 이번 달 쓴 양과 전체 양이 1 / 200 AI credits처럼 나오고, 왼쪽에 Resets on Dec 1처럼 초기화 날짜가 붙습니다. 이 무료 계정의 한 달 허용량은 200 AI 크레딧이었습니다.

1크레딧을 0.01달러로 치면 200크레딧은 2달러어치 사용량입니다. 유료 Pro가 한 달 1,500크레딧이니 무료는 Pro의 13% 남짓입니다. 요금제 페이지가 무료 칸에 숫자를 쓰지 않은 만큼, 내 계정 허용량은 이 창에서 직접 보는 게 가장 정확합니다.

초기화 시각은 사람마다 다르지 않습니다. 공식 문서는 매달 1일 00:00:00 UTC에 전체 양으로 되돌리고, 결제일과 상관없이 고정이라고 적었습니다. 한국 시간으로는 매달 1일 오전 9시입니다. 다 못 쓴 크레딧은 다음 달로 넘어가지 않고 사라집니다.

창 안에는 Refresh for latest usage라는 문구도 있습니다. 쓴 양이 바로 반영되지 않을 수 있으니, 숫자가 그대로면 페이지를 새로 고친 뒤 다시 열어 보면 됩니다. 아래쪽 Session token usage 칸에는 지금 열어 둔 대화에서 쓴 입력 토큰과 출력 토큰 합계가 따로 나옵니다.

질문 두 번에 든 토큰과 크레딧

실제로 얼마나 닳는지 보려고 무료 계정으로 성격이 다른 질문 두 개를 보냈습니다. 첫 번째는 엑셀에서 B열 날짜 중 이번 달 것만 세는 수식이었습니다. 답은 COUNTIFS와 EOMONTH를 묶은 수식 한 줄로, 이번 달 1일 이상이고 다음 달 1일 미만인 날짜만 세는 방식이었습니다.

두 번째는 폴더 안 사진 파일 이름을 찍은 날짜로 바꾸는 파이썬 스크립트였습니다. 45줄짜리 rename_photos.py 파일이 오른쪽 작업 창에 열렸고, 기본은 바뀔 이름만 보여 주고 --apply를 붙여야 실제로 바꾸게 짜 줬습니다. 다만 대상 확장자가 jpg, jpeg, tif, tiff 네 가지라서 아이폰 사진의 HEIC 파일이나 PNG 스크린숏은 건너뜁니다. 그대로 쓰려면 확장자 목록을 고쳐야 합니다.

답변 아래 게이지 아이콘을 누르면 그 답 하나에 든 토큰이 나옵니다. 수식 질문은 입력 10,119토큰, 출력 43토큰이었고 스크립트 질문은 입력 10,209토큰, 출력 747토큰이었습니다. 질문은 몇십 자인데 입력이 둘 다 1만 토큰을 넘었습니다. 내가 쓴 글자보다 기본으로 함께 들어가는 양이 훨씬 크다는 뜻이라, 질문을 짧게 줄인다고 크레딧이 눈에 띄게 아껴지지는 않습니다.

두 질문을 보낸 뒤 Included credits 칸은 1 / 200 AI credits였고, 사용량 막대는 0.1%만 찼습니다. 200크레딧의 0.1%면 0.2크레딧 정도입니다. 세션 합계는 입력 20,328토큰, 출력 790토큰이었습니다. 공식 문서도 가벼운 모델로 짧게 묻는 채팅은 1크레딧이 안 될 수 있고, 큰 모델로 여러 파일을 오가는 긴 에이전트 작업은 그만큼 더 든다고 설명합니다.

크레딧이 떨어지면, 유료 플랜과 차이

무료 플랜은 크레딧을 따로 살 수 없습니다. 요금제 페이지 비교표의 Purchase additional GitHub AI Credits 줄에서 무료만 Not included로 나옵니다. 200크레딧을 다 쓰면 유료 플랜으로 올리거나 다음 달 1일 오전 9시 초기화를 기다려야 합니다.

유료 플랜의 크레딧은 기본 크레딧과 Flex allotment(변동 추가분)를 더한 값입니다. Pro는 월 10달러에 기본 1,000과 추가분 500을 합쳐 1,500크레딧, Pro+는 39달러에 7,000크레딧, Max는 100달러에 20,000크레딧입니다. 기본 크레딧은 구독료와 같은 금액으로 고정이고, 추가분은 모델 가격이나 새 모델에 따라 바뀔 수 있다고 공식 문서에 적혀 있습니다. 유료 플랜은 크레딧을 다 쓴 뒤에도 추가 사용 예산을 걸어 이어서 쓸 수 있지만, 이 추가 사용에는 상한이 걸릴 수 있습니다.

코드 자동 완성은 따로 셉니다. 무료 플랜은 한 달 2,000회까지이고, 유료 플랜은 자동 완성과 다음 편집 제안(next edit suggestions)이 무제한이며 AI 크레딧에서 빠지지 않습니다. 반대로 채팅, 코파일럿 CLI, 클라우드 에이전트, Spaces, Spark, 클로드 코드나 코덱스 같은 외부 코딩 에이전트는 모두 크레딧을 씁니다.

학생이라면 계산이 조금 다릅니다. 깃허브 학생 인증을 받으면 Copilot Student 플랜을 쓸 수 있는데, 모델은 무료처럼 자동 선택만 되고 코드 완성은 무제한입니다. 학생 플랜의 크레딧 숫자도 공식 문서에는 적혀 있지 않습니다.

무료 크레딧 오래 쓰는 법

웹 채팅에서 크레딧을 좌우하는 건 질문 글자 수보다 대화 길이와 작업 종류입니다. 두 번째 질문의 입력은 첫 번째보다 90토큰 늘었는데, 앞 질문과 답을 합친 길이와 비슷한 양입니다. 같은 대화를 계속 이어 가면 앞 내용이 입력에 쌓이니, 주제가 바뀌면 왼쪽 위 New chat으로 새 대화를 여는 편이 낫습니다.

입력창 아래 All repositories 버튼과 파일, Spaces 추가 버튼은 필요할 때만 씁니다. 저장소나 파일을 붙이면 그 내용이 입력 토큰으로 들어갑니다. 코드 한 줄 설명처럼 저장소 전체가 필요 없는 질문은 붙이지 않고 묻는 쪽이 가볍습니다.

에이전트 모드와 코파일럿 CLI도 무료 플랜에서 쓸 수 있습니다. 요금제 페이지에 Free plan supports CLI and agent mode라고 적혀 있습니다. 다만 같은 200크레딧에서 빠지고, 여러 파일을 읽고 고치는 작업은 한 번에 많이 쓰기 쉽습니다. 월말이 가까우면 게이지 창을 한 번 열어 남은 양부터 보는 습관이 도움이 됩니다.

게이지 창의 초록색 Upgrade 버튼은 유료 플랜 결제 화면으로 넘어가는 버튼입니다. 남은 양만 볼 때는 누를 필요가 없고, 창 바깥을 누르거나 Esc를 누르면 닫힙니다.
