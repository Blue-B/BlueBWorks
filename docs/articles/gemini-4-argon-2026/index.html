덧붙임

처음 글은 100만 토큰을 컨텍스트 크기로 설명했지만 9월 30일 원문은 출력 한도 확대를 말하고 있었다. 이 차이는 API 기본값 65,536 토큰과 long decode 설정으로 이어지기 때문에, 개정본은 숫자의 뜻과 실제 호출 방법, 출력 요금을 중심으로 다시 썼다.

제미나이 4 아르곤의 100만 토큰은 컨텍스트가 아니라 출력 한도다

수만 줄짜리 코드 마이그레이션이나 긴 증명을 모델에 맡겨 본 사람이라면 답이 중간에 끊기는 경험을 해 봤을 것이다. 이전 Gemini 모델은 한 번에 내놓을 수 있는 출력이 사고(thinking) 과정을 포함해 64K 토큰에서 멈췄다. 그래서 큰 변경은 여러 번 나눠 요청하고, 사람이 조각을 이어 붙여야 했다.

Google은 2026년 9월 30일 Gemini 4 Argon(제미나이 4 아르곤)을 발표하며 이 부분을 바꿨다고 밝혔다. 발표 원문은 더 길고 복잡한 작업을 위해 모델의 출력 토큰 한도를 이전 64K에서 업계 최고 수준인 100만 토큰으로 크게 늘린다고 적었다. 모델이 한 번의 실행 궤적 안에서 수십만 토큰을 생각하고 생성할 여유가 생기면, 어려운 문제를 한 번에 풀 수 있는 추론 깊이가 생긴다는 설명이다.

이 글의 처음 판본(10월 2일 게시)은 반대로 '100만 출력 토큰이 아니라 100만 토큰 컨텍스트'가 핵심이라고 적었다. 원문을 다시 확인한 결과 이 설명은 틀렸다. 9월 30일 발표문에는 컨텍스트 창 크기가 나오지 않고, 100만이라는 숫자는 출력 한도 문장에만 나온다. 정정 내용은 글 아래 정정 기록에 남겼다.

그렇다면 입력은 얼마나 넣을 수 있을까. 10월 13일 공개된 Gemini API 모델 문서는 아르곤의 컨텍스트 창을 1,048,576 토큰으로 적고, 이를 '입력과 출력을 합친 통합 한도'라고 설명한다. 입력, 사고, 응답이 같은 창을 나눠 쓴다는 뜻이다. 입력을 많이 넣을수록 출력에 쓸 수 있는 몫은 그만큼 줄어든다.

아래 도식은 이 관계를 막대로 그린 것이다. 이전 모델은 출력이 64K에서 멈췄고, 아르곤은 기본 호출에서도 출력이 65,536 토큰으로 같다. long decode를 켜야 창에서 입력을 뺀 나머지까지 출력을 늘릴 수 있다. 숫자만 보고 바로 100만 토큰 답이 나온다고 기대하면 안 되는 이유다.

API에서 100만 토큰 출력을 쓰는 방법: 기본 64K와 long decode

Google 개발자 가이드에 따르면 Interactions API에서 아르곤을 부르면 스트리밍이든 아니든 출력 한도가 65,536 토큰으로 정해진다. 기존 코드를 그대로 쓰면 출력은 예전처럼 64K에서 끝난다는 뜻이다. 이 기본값 덕분에 기존 앱이 갑자기 긴 답을 받아 비용이 튀는 일은 막을 수 있다.

64K를 넘기려면 요청을 백그라운드 작업으로 보내야 한다. 가이드는 background=True를 켜고 generation_config의 max_output_tokens를 65,536보다 크게 지정하라고 안내한다. 요청은 바로 끝나지 않으므로 interaction의 상태가 in_progress나 queued인 동안 주기적으로 다시 조회하고, 끝나면 여러 model_output 단계에 나뉘어 담긴 텍스트를 이어 붙여 읽는다.

max_output_tokens를 얼마로 둘지는 비용 판단이다. 가이드는 사고가 답을 잘라 먹지 않을 만큼 크게, 어려운 프롬프트가 한도를 다 써도 감당할 만큼 작게 정하라고 권한다. 예를 들어 출력 262,144 토큰을 다 쓰면 도입가 기준 약 2.62달러, 12월 1일 이후 가격으로는 약 5.24달러가 출력 요금으로 나온다.

예전 GenerateContent API를 쓰는 경우에는 방식이 다르다. 가이드는 더 세밀하게 제어하려면 클라이언트가 직접 이어 쓰기를 요청하는 방식(client-side continuation)을 쓸 수 있고, 이 방식은 현재 레거시 GenerateContent API에서만 된다고 설명한다. Interactions API에도 곧 들어온다고 했지만 날짜는 밝히지 않았다.

제미나이 4 아르곤 출시일과 사용 범위: 9월 30일 발표, 10월 13일 개발자 공개

발표일과 실제로 쓸 수 있게 된 날은 다르다. 9월 30일 발표 당시 아르곤은 Google DeepMind의 Fairwind 프로그램에 참여한 신뢰된 사이버 방어 조직에만 먼저 열렸다. Google은 미국 정부의 자발적인 출시 전 모델 접근 절차에 참여하면서 접근 범위를 단계적으로 넓히겠다고 밝혔다.

개발자 공개는 2주 뒤인 10월 13일이었다. Google 블로그와 개발자 가이드는 이날부터 Google AI Studio와 Android Studio에서 Gemini API 유료 등급으로 아르곤을 쓸 수 있고, Google AI Ultra 구독자는 AI Studio와 에이전트 개발 플랫폼 Google Antigravity에서 써 볼 수 있다고 안내했다. 모델 ID는 gemini-4-argon이다.

무료로 써 볼 수 있는지 찾는 사람이 많지만 답은 '아니오'다. Gemini API 가격 페이지는 아르곤이 무료 등급에서 제공되지 않는다고 명시한다. 유료 등급에 결제 수단을 연결해야 API로 호출할 수 있다.

이 글을 처음 쓴 10월 2일에는 일반 개발자가 쓸 방법이 없었다. 개정본은 10월 29일 기준 상태를 반영했다. 같은 계열의 다음 모델인 제미나이 4 카본은 10월 28일 발표됐고 아직 일반 개발자에게 열리지 않았으니, 두 모델의 제공 상태를 혼동하지 않도록 주의한다.

제미나이 4 아르곤 가격: 도입가는 11월 30일까지, 사고 토큰도 출력 요금

Google은 9월 30일 발표에서 도입가를 100만 토큰당 입력 2달러, 출력 10달러, 캐시된 입력은 입력가에서 95% 할인으로 예고했다. Gemini API 가격 페이지는 이 가격이 2026년 11월 30일까지이고, 12월 1일부터 입력 4달러, 출력 20달러로 오른다고 적고 있다. 캐시 입력은 0.10달러에서 0.20달러가 된다.

출력 요금에는 사고 토큰이 들어간다. 가격 페이지는 그라운딩을 쓸 때 내부 도구 시스템 안내와 함수 선언까지 모델이 처리한 모든 토큰을 세어 청구한다고 밝힌다. long decode로 출력 한도를 크게 열면 답의 길이보다 사고에 쓴 토큰이 비용을 좌우할 수 있다.

캐시는 자동으로 적용되는 암시적 캐싱만 지원한다. 개발자 가이드는 명시적으로 캐시를 만들어 넘기던 코드를 걷어 내라고 안내한다. 같은 저장소 설명이나 긴 문서를 반복해서 넣는 에이전트라면 앞부분을 고정해 캐시 할인을 받는 구조가 유리하다.

Google 검색 그라운딩은 별도 요금이다. Gemini 3 이후 모델이 공유하는 월 5,000건 무료 요청을 넘으면 1,000건당 14달러가 붙는다. 한 요청이 여러 번의 검색으로 이어질 수 있어, 조사형 에이전트는 토큰 요금과 검색 요금을 따로 계산해야 한다.

Google이 밝힌 아르곤 성능과 내부 사용 사례, 어떻게 읽을까

Google은 발표문에서 내부 사례를 여럿 들었다. 아르곤 에이전트 팀이 데이터센터 전체의 프로파일링 기록을 분석해 메모리 최적화를 찾아 적용했고, 배포 뒤 300TiB가 넘는 메모리를 확보했으며 전체 절감 규모를 500TiB에서 1PiB로 추정한다고 했다. 양자 컴퓨팅 연구에서는 서브루틴의 자원 사용을 최적화해 공개된 기준치보다 40% 나은 결과를 몇 분 만에 냈다고 한다.

코드 마이그레이션 사례는 개발자에게 더 가깝다. Google은 아르곤 에이전트가 re2, libgav1 같은 핵심 라이브러리의 수만 줄부터 Fuchsia Zircon 커널의 80만 줄 이상까지 C/C++ 코드를 Rust로 옮기는 작업을 하고 있다고 밝혔다. 중요한 시스템이라 자동·수동 감사와 에뮬레이션 테스트, 검토를 거친 뒤 운영에 반영한다는 조건도 함께 적었다.

영상 디코더 libgav1의 예가 구체적이다. 아르곤 에이전트는 기존 Rust 포팅본에서 SIMD 코드 3만 2천 줄을 걷어 내고, 프로파일 기반 실험을 여러 번 돌리며 컴파일러 출력을 살펴 컴파일러가 자동으로 벡터화할 수 있는 안전한 Rust 코드를 만들었다. 결과는 같은 영상 출력을 내면서 Rust 포팅본보다 2.7배 빠른 메모리 안전 디코더였다고 한다.

벤치마크로는 실제 장기 소프트웨어 작업을 재는 DeepSWE v1.1 77.9%, 비즈니스 업무 자동화를 재는 AutomationBench 51.3%, 긴 영상 이해를 재는 LVBench 91.7%, 취약점 수정 평가 CWE-bench v1 68%(공동 1위)를 제시했다. 모두 Google이 발표한 값이고 측정 조건이 평가마다 다르다. 독립 재현 결과로 읽으면 안 된다.

도입을 판단할 때는 이 숫자보다 내 코드베이스에서의 결과가 중요하다. 이미 겪었던 버그 수정이나 작은 마이그레이션 과제를 몇 개 골라 기존 모델과 같은 조건으로 돌리고, 완료율과 재시도 횟수, 출력 토큰을 포함한 총비용을 함께 비교하는 편이 판단에 쓸모 있다.

기존 Gemini 코드에서 아르곤으로 옮길 때 바꿀 설정

모델 이름만 바꾸면 끝나지 않는다. 개발자 가이드는 사고량을 정하던 thinking_budget을 thinking_level로 바꾸라고 안내한다. 값은 low, medium, high 세 가지이고 기본값은 medium이다. thinking_budget은 더 이상 권장되지 않아 경고가 돌아온다.

temperature, top_p, top_k 같은 샘플링 설정도 정리해야 한다. 아르곤은 이 값들을 무시하고 경고를 돌려준다. 출력의 다양성을 이 값으로 조절하던 코드는 결과가 기대와 다를 수 있으니 프롬프트와 thinking_level로 조절 방식을 옮겨야 한다.

시간 초과 설정도 다시 본다. 가이드는 어려운 추론 요청이 몇 분씩 걸릴 수 있다며 Interactions API의 background=True를 쓰거나 HTTP 클라이언트의 시간 제한을 최소 15~20분으로 늘리라고 권한다. 기존 30초나 60초 제한을 그대로 두면 요청이 중간에 끊긴 것처럼 보인다.

가이드는 긴 작업을 맡기기 전에 목표와 성공 기준을 먼저 합의하고, 테스트 모음이나 검증 스크립트처럼 모델이 스스로 결과를 확인할 수단을 주라고 권한다. 확인 수단이 있으면 기준치를 기록하고 바꿀 때마다 다시 재며 목표에 닿을 때까지 반복할 수 있다는 설명이다.

자주 묻는 질문: 제미나이 4 아르곤 100만 토큰, 무료 여부, 가격

검색으로 많이 찾는 질문을 공식 자료 기준으로 짧게 정리했다. 날짜와 가격은 2026년 10월 29일 확인 기준이다.

제미나이 4 아르곤의 100만 토큰은 컨텍스트 창인가요, 출력 한도인가요?

9월 30일 Google 발표의 100만 토큰은 출력 한도로, 이전 64K에서 늘어났습니다. Gemini API 문서는 입력과 출력을 합친 컨텍스트 창도 1,048,576 토큰이라고 적고 있어, 입력·사고·출력이 같은 창을 나눠 씁니다. 기본 출력은 65,536 토큰이고 long decode를 켜야 그 이상 출력합니다.

제미나이 4 아르곤은 무료로 쓸 수 있나요?

아닙니다. Gemini API 가격 페이지는 아르곤을 무료 등급에서 제공하지 않는다고 명시합니다. 10월 13일부터 Gemini API 유료 등급과 Google AI Ultra 구독자에게 제공됩니다.

제미나이 4 아르곤 API 가격은 얼마인가요?

100만 토큰당 입력 2달러, 출력 10달러(사고 토큰 포함), 캐시 입력 0.10달러가 11월 30일까지의 도입가입니다. 12월 1일부터 입력 4달러, 출력 20달러, 캐시 입력 0.20달러로 오릅니다.

제미나이 4 아르곤 출시일은 언제인가요?

Google은 2026년 9월 30일 발표하며 사이버 방어 조직부터 제한 제공했고, 개발자 대상 공개는 2026년 10월 13일입니다.

정정 기록

  • 2026년 10월 29일

    처음 글(2026-10-02)은 공식 발표가 '100만 출력 토큰이 아니라 100만 토큰 컨텍스트'를 강조했다고 썼으나 틀렸다. 9월 30일 Google 발표 원문은 'we are significantly expanding the model's output token limit to an industry-leading 1M tokens, up from the previous 64K tokens'라고 출력 토큰 한도를 64K에서 100만으로 늘린다고 밝혔고, 컨텍스트 창 크기는 발표문에 없었다. 제목·요약·핵심 요약·본문을 고쳤고, 10월 13일 공개된 Gemini API 문서의 통합 1,048,576 토큰 창과 기본 출력 65,536 토큰을 함께 적었다. 같은 날 제공 범위·가격·사용법을 더한 장문 해설로 개정했다. 발표일과 최초 게시일은 바꾸지 않았다.
