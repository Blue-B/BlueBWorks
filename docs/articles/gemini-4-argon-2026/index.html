Gemini 4 Argon 발표 — 100만 컨텍스트로 장기 코딩·사이버 방어를 겨냥한다

Google이 복잡한 장기 작업을 겨냥한 Gemini 4 Argon을 발표했다. 공식 발표에서 강조한 것은 ‘100만 출력 토큰’이 아니라 100만 토큰 컨텍스트와 장기 추론이며, 현재는 Fairwind 프로그램의 신뢰된 사이버 방어 조직부터 제한적으로 배포 중이다.

공식 출처

Google — Gemini 4 Argon blog.google

먼저 볼 것

  • 공식 설명 기준 100만 토큰 컨텍스트를 지원한다.
  • 코딩·기업 지식 업무·방어적 사이버 보안을 장기 작업 사례로 제시한다.
  • 초기 가격은 입력 $2·출력 $10/100만 토큰으로 예고됐지만 일반 공개 전 단계다.

편집 메모

Argon은 지금 당장 누구나 API 키로 호출할 수 있는 모델이 아니다. 그래서 벤치마크보다 중요한 정보는 접근 범위와 Google이 실제 내부 장기 작업에 어떻게 쓰고 있는지다. 대규모 코드 마이그레이션과 보안 작업을 모델 한 번의 응답이 아니라 긴 실행 궤적으로 다루는 방향이 더 뚜렷해졌다.

발표에서 확인된 것

Google은 9월 30일 Gemini 4 Argon을 공개하며 복잡하고 긴 작업에서 추론을 지속하는 프런티어 모델이라고 설명했다. 100만 토큰 규모의 컨텍스트를 핵심 사양으로 제시했고, 소프트웨어 엔지니어링·법률 및 금융 리서치·방어적 사이버 보안을 대표 사용처로 들었다.

‘긴 컨텍스트’보다 중요한 변화

100만 토큰 자체보다 주목할 부분은 모델을 긴 실행 단위에 투입하는 방식이다. Google은 내부에서 대규모 C/C++→Rust 마이그레이션, 메모리 최적화 탐색, 반복적인 프로파일 기반 실험처럼 한 번의 답으로 끝나지 않는 작업에 Argon 에이전트를 쓰고 있다고 밝혔다. 즉 문서를 많이 넣는 능력보다 여러 단계의 상태를 유지하며 작업을 이어가는 방향에 초점이 있다.

현재 누가 쓸 수 있나

일반 개발자 전체에게 즉시 열린 API 출시는 아니다. Google은 Fairwind Program에 참여하는 신뢰된 사이버 방어 조직에 먼저 제공하고, 사전 안전성 검토와 피드백을 거쳐 개발자·기업·소비자 접근을 확대하겠다고 밝혔다. 도입 검토 시 ‘모델이 발표됐다’와 ‘내 계정에서 사용할 수 있다’를 구분해야 한다.

가격과 판단 포인트

Google은 정식 확대 시점의 도입 가격으로 입력 100만 토큰당 2달러, 출력 10달러, 캐시 입력 95% 할인을 예고했다. 다만 실제 비용은 장기 에이전트가 수행하는 반복 호출·도구 사용·검증 횟수에 크게 좌우된다. 공개 확대 뒤에는 단일 벤치마크보다 실제 코드베이스에서 완료율과 재시도 횟수, 총 비용을 함께 비교하는 편이 유효하다.
