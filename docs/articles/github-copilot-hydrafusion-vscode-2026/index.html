개발도구 Research preview

GitHub가 Copilot CLI에서 시험하던 HydraFusion을 VS Code와 GitHub Copilot 앱으로 확대했다. 단일 모델을 고르는 대신 작업에 따라 한 모델, 단계적 승격, 다른 모델의 비평 후 수정 같은 여러 실행 흐름을 자동 선택한다.

먼저 볼 것

  • 한 요청 안에서 여러 모델을 조합할 수 있다.
  • Single·Cascade·Critique 실행 흐름을 작업에 맞게 선택한다.
  • VS Code와 Copilot 앱으로 연구 프리뷰 범위가 확대됐다.

편집 메모

HydraFusion은 ‘가장 좋은 모델 하나’를 고르는 문제를 런타임이 해결하려는 시도다. 요청마다 Single·Cascade·Critique 흐름을 달리 쓰기 때문에, 앞으로 코딩 도구의 차별점이 모델 목록보다 모델을 조합하고 검증하는 오케스트레이션으로 이동할 가능성을 보여준다.

무엇이 나왔나

HydraFusion은 하나의 모델이 아니라 여러 모델과 실행 방식을 조합하는 Copilot의 연구 프리뷰다. 이번 업데이트로 VS Code와 GitHub Copilot 앱에서 사용할 수 있게 됐고, Single·Cascade·Critique 세 가지 흐름 중 작업에 맞는 방식을 선택한다.

개발자에게 왜 중요한가

코딩 도구에서 사용자가 매번 모델을 직접 고르는 대신 도구가 비용과 품질을 고려해 모델 조합과 검토 흐름까지 선택하는 방향이 실제 제품으로 들어오고 있다. 특히 긴 구현이나 디버깅에서 '어떤 모델이 최고인가'보다 '어떤 모델들을 어떤 순서로 쓸 것인가'가 중요한 설계 요소가 될 수 있다.

직접 써볼 때 알아둘 점

VS Code 1.140 이상에서 모델 선택기로 사용할 수 있고, 조직 계정은 관리자가 프리뷰 기능을 허용해야 할 수 있다. 아직 연구 프리뷰이므로 동작 방식과 제공 범위는 바뀔 수 있고, Auto와 달리 한 요청 안에서 여러 모델을 조합한다는 차이를 확인하는 게 좋다.
