GPT-6.1 Sol은 어떤 모델인가: Astra에 가까운 성능을 5분의 1 가격에

에이전트에게 코드 수정이나 문서 분석을 맡겨 보면 모델 선택이 곧 비용 선택이 된다. 가장 똑똑한 모델을 쓰면 결과는 좋지만, 같은 작업을 하루 수백 번 돌리면 청구서가 감당하기 어려워진다. OpenAI가 2026년 9월 29일 공개한 GPT-6.1 Sol은 이 고민을 겨냥한 모델이다.

OpenAI는 GPT-6.1 Sol을 GPT-6 Sol의 업그레이드 모델로 소개하며, 에이전트형 코딩과 컴퓨터 사용, 전문 업무에서 GPT-6 Astra에 가까운 지능을 Astra 표준 입력·출력 가격의 5분의 1로 제공한다고 밝혔다. 같은 시기 OpenAI 모델은 가장 지능적인 Astra, 그 아래 Sol, 대량 일상 업무용 Luna의 세 단계로 나뉜다.

가격 차이는 크다. 100만 토큰당 Astra는 입력 10달러·출력 50달러, Sol은 입력 2달러·출력 10달러, Luna는 입력 0.10달러·출력 0.50달러다. 캐시된 입력은 Sol이 0.10달러로, 표준 입력보다 95% 낮고 이전 GPT-6 Sol의 캐시 입력가보다도 50% 낮다고 OpenAI는 설명한다.

캐시 가격이 중요한 이유는 에이전트의 작동 방식에 있다. 에이전트는 같은 저장소 설명, 도구 정의, 이전 대화를 매 요청마다 다시 보낸다. 이 반복되는 앞부분이 캐시로 처리되면 실제 입력 비용은 표준가보다 훨씬 낮아진다. OpenAI가 캐시 가격을 강조하며 요청 간 컨텍스트를 재사용하는 에이전트를 더 자유롭게 운영할 수 있다고 쓴 것도 이 때문이다.

GPT-6.1 Sol 성능: 코딩·컴퓨터 사용 벤치마크를 읽는 법

OpenAI는 성능을 대부분 'Astra와의 차이'와 '작업당 비용'으로 설명했다. 실제 코드베이스의 장기 소프트웨어 작업을 재는 DeepSWE v1.1에서 Sol은 약 5분의 1 비용으로 Astra와 대등했고, 더 낮은 추론 강도로 이전 GPT-6 Sol의 최고 점수보다 6.4%포인트 높았다고 한다.

컴퓨터 사용 평가인 OSWorld 2.0 오프라인 세트에서는 최대 추론 강도로 이전 Sol보다 7%포인트 높으면서 비용은 절반 미만이었고, Astra와의 차이는 2.1%포인트, 작업당 비용은 약 7분의 1이었다고 밝혔다. 여러 도구를 쓰는 업무 자동화 평가 AutomationBench에서는 중간 추론 강도로 이전 Sol보다 4.8%포인트 높았다.

과학 연구 작업을 재는 Terminal-Bench Science 0.1에서는 Sol이 이전 Sol 점수의 2배 이상을 기록했고, 최대 추론 강도의 평균 작업당 비용은 5.47달러였다. 같은 평가에서 Astra는 23.80달러였다. 다만 OpenAI는 Astra가 68.1%로 여전히 가장 높으니 가장 어려운 과학 연구에는 Astra를 쓰라고 직접 권했다.

이 숫자들은 모두 OpenAI가 자체 연구 환경이나 API로 측정한 값이다. 경쟁사 수치는 공개 보고서에서 인용했고, 시스템 프롬프트와 도구 차이 때문에 ChatGPT의 실제 결과와 다를 수 있다고 OpenAI도 밝혔다. 내 작업에서 같은 결과가 나온다는 보장으로 읽기보다, 어떤 작업에서 Sol로 내려가도 될지 후보를 고르는 참고로 쓰는 편이 맞다.

사실 정확성도 올랐다고 한다. 이전 모델의 오류를 사용자가 신고한 대화를 비식별화해 만든 평가에서, 낮은 추론 강도의 사실 오류 포함 응답 비율이 11.4%에서 7.7%로 약 32% 줄었다. 다만 일부러 어려운 프롬프트를 모은 평가라 일상적인 사용에서의 오류율을 뜻하지는 않는다고 OpenAI는 덧붙였다.

GPT-6.1 Sol 사용 방법: ChatGPT Work·Codex와 API 모델 ID

ChatGPT에서는 쓰는 곳이 정해져 있다. OpenAI는 발표일부터 Plus, Pro, Business, Enterprise, Edu 사용자가 ChatGPT Work와 Codex에서 GPT-6.1 Sol을 쓸 수 있고, 일반 Chat에서는 아직 쓸 수 없다고 밝혔다. 대화창에서 모델 목록을 찾다가 없다고 당황할 필요는 없다.

개발자는 API에서 gpt-6.1-sol이라는 모델 ID로 부른다. API 모델 문서에 따르면 입력은 텍스트와 이미지, 출력은 텍스트이고, 컨텍스트 창은 1,050,000 토큰, 최대 출력은 128,000 토큰, 지식 기준일은 2026년 4월 30일이다. 무료 등급에서는 쓸 수 없다.

추론 강도(reasoning.effort)는 low, medium, high, xhigh, max 다섯 단계이고 기본값은 medium이다. 웹 검색, 파일 검색, 코드 인터프리터, 컴퓨터 사용, MCP 같은 도구를 붙이려면 Responses API를 써야 한다고 문서는 명시한다. Chat Completions로 부르던 코드에서 도구를 쓰고 있다면 이 부분부터 확인해야 한다.

OpenAI는 발표 당시 며칠 안에 Codex에서 표준 속도보다 최대 8배 빠르게 토큰을 생성하는 GPT-6.1 Sol Ultrafast를 제공할 예정이라고 했다. API 문서 기준으로 Ultrafast 모드 가격은 표준의 6배이고, Fast 모드는 2배, Batch와 Flex는 50% 낮다. 속도를 사는 대신 단가가 크게 오른다는 점을 염두에 둔다.

처리량 한도는 사용 등급에 따라 다르다. 모델 문서 기준 Build 등급은 분당 요청 5,000건과 분당 토큰 100만 개, Launch는 1만 건과 400만 개, Grow는 1만 5천 건과 4,000만 개다. 등급은 요청과 지출이 늘면 자동으로 올라간다. 긴 문서를 한꺼번에 넣는 에이전트라면 분당 토큰 한도에 먼저 걸릴 수 있으니 내 계정 등급부터 확인해 두는 편이 좋다.

GPT-6.1 Sol API 요금: 272K 입력을 넘으면 요청 전체가 비싸진다

표준 단가만 보고 예산을 잡으면 긴 문서 작업에서 틀리기 쉽다. API 모델 문서는 입력이 272K 토큰을 넘는 프롬프트에 대해 요청 전체의 입력과 캐시 요금을 2배, 출력 요금을 1.5배로 계산한다고 적고 있다. 272K를 넘긴 부분만이 아니라 요청 전체에 붙는다는 점이 핵심이다.

예를 들어 캐시 없이 입력 250K, 출력 20K를 보내면 0.50달러와 0.20달러를 더해 약 0.70달러다. 입력을 300K로 늘리면 입력 단가가 4달러, 출력 단가가 15달러가 되어 1.20달러와 0.30달러, 약 1.50달러가 된다. 입력은 20% 늘었지만 요금은 2배 넘게 오른다. 이 계산은 BlueBWorks가 문서의 배율로 직접 한 것이다.

그래서 긴 저장소나 문서를 통째로 넣기 전에 정말 필요한 부분만 고르는 편이 비용에 직접 효과가 있다. 검색으로 관련 파일만 넣거나, 대화가 길어지면 요약해 이어 가는 식으로 입력을 272K 아래에 묶어 두면 같은 작업을 더 싸게 돌릴 수 있다.

캐시 쓰기도 따로 계산된다. 문서는 캐시 쓰기를 표준 입력 단가의 1.25배인 2.50달러, 캐시된 입력은 5%인 0.10달러로 적고 있다. 지역 처리를 쓰면 10%가 더 붙는다. 반면 Codex와 ChatGPT Work는 기본 500K 컨텍스트를 쓰고, 구독 사용량에는 장문 추가 요금이 없다고 문서는 밝힌다.

급하지 않은 작업은 요금을 절반으로 줄일 수 있다. 문서는 Batch와 Flex 가격이 표준보다 50% 낮다고 적고 있다. 밤사이 돌리는 코드 점검이나 문서 분류처럼 결과를 바로 받지 않아도 되는 일은 이 방식으로 돌리는 편이 비용에 유리하다.

Astra 대신 Sol을 쓸 작업, Sol 대신 Astra를 쓸 작업

OpenAI 발표를 바탕으로 정리하면 Sol이 맞는 작업은 반복 횟수가 많고 결과를 검증할 수 있는 일이다. 코드 수정과 테스트, PDF 문서에서 답 찾기, 여러 업무 도구를 오가는 자동화처럼 성공 여부를 확인할 수 있는 작업은 Sol로 먼저 돌리고, 실패한 경우만 Astra로 올리는 구성이 가능하다.

반대로 OpenAI 스스로 Astra를 권한 영역이 있다. Terminal-Bench Science에서 Astra가 가장 높은 점수를 냈다며, 가장 어려운 과학 연구 작업에는 Astra를 쓰라고 했다. 실패 비용이 큰 단발성 분석이나 검증 수단이 없는 판단에는 단가보다 정확도가 중요하다.

기존 GPT-6 Sol로 에이전트를 운영하고 있었다면 비교는 간단하다. 같은 과제 묶음을 두 모델로 돌려 완료율, 도구 호출 횟수, 재시도 횟수, 총 토큰 비용을 기록한다. 추론 강도를 한 단계 낮춰도 이전 모델보다 결과가 좋은지 확인하면 비용을 더 줄일 수 있다.

안전 면에서 OpenAI는 Sol이 검색 도구가 작동하지 않을 때 이를 숨기지 않고 알리고, 에이전트 작업 중 승인되지 않은 결과를 막는 항목에서 이전 Sol보다 실패율이 낮았다고 밝혔다. 자세한 평가는 시스템 카드 부록에 있다.

GPT-6.1 Sol을 무료로 쓸 수 있나요?

API 무료 등급은 지원하지 않습니다. ChatGPT에서는 Plus, Pro, Business, Enterprise, Edu 사용자가 ChatGPT Work와 Codex에서 쓸 수 있고, 일반 Chat에서는 아직 제공되지 않습니다.

GPT-6.1 Sol의 컨텍스트 창과 최대 출력은?

API 기준 컨텍스트 창은 1,050,000 토큰, 최대 출력은 128,000 토큰입니다. Codex와 ChatGPT Work에서는 기본 500K 컨텍스트를 씁니다.

GPT-6 Astra와 차이는 무엇인가요?

Sol은 Astra 표준 가격의 5분의 1이고, OpenAI 측정으로 DeepSWE에서 대등, OSWorld 2.0에서 2.1%포인트 낮습니다. 가장 어려운 과학 연구에는 OpenAI도 Astra를 권합니다.
