GPT‑6.1 Sol 출시 — 코딩·컴퓨터 사용 중심으로 Sol이 업데이트됐다

OpenAI가 GPT‑6.1 Sol을 공개했다. 에이전트형 코딩, 컴퓨터 사용, 전문 업무 성능을 강화하고 Astra 대비 낮은 표준 API 가격을 강조한 업데이트다.

글 작성: BlueBWorks (AI 보조)

요약
  • API 문서 기준 1,050,000 컨텍스트와 128,000 최대 출력 토큰을 지원한다.
  • 코딩·컴퓨터 사용·전문 업무를 비용 효율 중심으로 겨냥한다.
  • Responses API에서 도구 호출을 지원하고 reasoning effort를 조절할 수 있다.
덧붙임

GPT‑6.1 Sol의 포지션은 ‘최고 성능’보다 ‘긴 에이전트 작업을 감당할 비용대’에 가깝다. 공식 API 문서 기준 105만 컨텍스트와 12.8만 최대 출력, 여러 reasoning effort를 지원한다. 모델 비교 시 토큰 단가만 보지 말고 한 작업이 끝날 때까지의 재시도와 도구 호출까지 합친 총비용을 보는 게 맞다.

무엇이 나왔나

GPT‑6.1 Sol은 GPT‑6 Sol 계열의 새 모델이다. OpenAI는 특히 agentic coding, computer use, 전문 업무에서의 향상을 강조했고 API와 ChatGPT의 여러 플랜에 제공한다고 발표했다.

개발자에게 왜 중요한가

코드 생성 자체보다 도구 호출, 여러 단계 작업, 화면 조작처럼 에이전트가 실제 일을 이어가는 용도가 모델 선택의 중심이 되고 있다는 흐름을 보여준다.

직접 써볼 때

기존 Sol 기반 에이전트가 있다면 같은 작업에서 성공률, 도구 호출 횟수, 총 토큰 비용과 완료 시간을 함께 비교하는 게 유용하다. 단순 벤치마크 숫자보다 실제 워크플로의 비용과 재시도 횟수를 보는 편이 낫다.
