개발도구 Public preview

GitHub가 Copilot CLI와 Copilot 앱의 macOS·Windows 버전에 컴퓨터 사용 기능을 공개 프리뷰로 추가했다. 화면을 읽고 클릭·입력·스크롤·드래그를 수행할 수 있어 API나 CLI, MCP가 없는 GUI 전용 업무까지 자동화 범위가 넓어진다.

공식 출처

GitHub Changelog — GitHub Copilot can now interact with desktop apps with computer use github.blog

먼저 볼 것

  • Copilot CLI와 macOS·Windows 앱에서 데스크톱 앱을 조작한다.
  • 클릭·입력·스크롤·드래그 같은 GUI 행동을 수행할 수 있다.
  • 앱 제어 전에 승인을 요구하며 조직 관리자가 기능을 끌 수 있다.

편집 메모

API와 MCP가 없는 오래된 사내 프로그램까지 자동화 범위에 들어온다는 점이 가장 크다. 반대로 화면 조작은 구조화된 API 호출보다 실패 원인이 많고 권한 범위도 넓다. 처음부터 전사 자동화를 노리기보다 반복적이고 되돌릴 수 있는 GUI 업무부터 붙이는 편이 맞다.

무엇이 나왔나

GitHub Copilot의 computer use가 Copilot CLI와 GitHub Copilot 앱에서 macOS·Windows 공개 프리뷰로 제공된다. 접근 가능한 앱 내용과 화면 맥락을 읽고 버튼 클릭, 텍스트 입력과 수정, 키 입력, 스크롤, 드래그 같은 일반적인 데스크톱 조작을 수행할 수 있다.

개발자에게 왜 중요한가

에이전트 자동화가 API·명령줄·MCP가 있는 도구에만 묶이지 않게 된 점이 크다. 오래된 사내 프로그램이나 GUI 전용 소프트웨어처럼 통합 수단이 부족한 환경도 사람이 하던 화면 조작 흐름 자체를 자동화 대상으로 삼을 수 있다.

직접 써볼 때 알아둘 점

현재는 공개 프리뷰이고 Copilot이 앱 제어를 시작하기 전에 승인을 요청한다. macOS에서는 접근성·화면 기록 권한이 필요하고 조직 관리자는 기능을 비활성화할 수 있으므로 민감한 앱이나 데이터가 포함된 작업은 허용 범위를 좁게 잡는 편이 좋다.
