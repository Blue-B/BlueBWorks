에이전트 Rolling out

OpenAI가 DevDay 2026에서 장기 작업을 맡길 수 있는 always-on 에이전트 Dots를 공개했다. 자체 클라우드 컴퓨터와 플러그인 연결을 사용하고, 피드백을 통해 사용자의 작업 방식을 익히는 형태다.

편집 메모

Dots를 단순한 ‘더 똑똑한 챗봇’으로 보면 핵심을 놓친다. 독립 클라우드 컴퓨터·고유 권한·지속 작업을 기본 단위로 둔다는 점에서 제품의 중심이 대화 세션에서 책임 단위로 이동했다. 실제 활용에서는 능력보다 어떤 앱을 연결하고 어떤 행동을 사전 승인할지 정하는 운영 설계가 더 중요해진다.

무엇이 나왔나

Dots는 ChatGPT 안팎에서 계속 실행되는 에이전트다. OpenAI 설명에 따르면 GPT-6 Astra 기반이며 자체 클라우드 컴퓨터를 사용하고, 수천 개의 앱과 연결할 수 있는 플러그인 생태계를 활용한다.

개발자에게 왜 중요한가

한 번 질문하고 답을 받는 챗봇보다, 목표를 맡겨두고 여러 도구를 사용해 계속 진행하는 에이전트가 별도 제품 형태로 자리잡기 시작했다는 점이 크다. 반복 모니터링, 자료 수집, 운영 업무처럼 시간이 이어지는 작업 설계가 더 중요해진다.

직접 볼 때 체크할 점

항상 실행되는 만큼 어떤 앱에 연결하는지, 어떤 작업을 스스로 수행할 수 있는지, 승인과 권한 범위가 어떻게 제한되는지를 함께 확인하는 게 좋다.
