공식 출처

Anthropic — Customize Claude Code with mods in TypeScript claude.com

먼저 볼 것

  • TypeScript 함수로 도구 호출·권한 판단·UI 이벤트에 개입한다.
  • 팀 내부 가드레일과 감사 로깅을 플러그인으로 만들 수 있다.
  • 샌드박스 격리가 아니므로 설치 출처를 엄격히 관리해야 한다.

편집 메모

Mods는 단순 명령 모음이 아니라 Claude Code의 행동 경로에 코드를 끼워 넣는 확장점에 가깝다. 조직용 개발 환경에서는 권한·감사·사내 도구 연결을 제품 업데이트와 독립적으로 구현할 수 있다는 장점이 있지만, 같은 이유로 신뢰하지 않는 Mod를 설치할 때의 위험도 훨씬 크다.

무엇이 나왔나

Claude Code Mods는 Claude Code가 도구를 호출하거나 권한을 묻고 화면을 그리는 등의 이벤트에 연결되는 작은 TypeScript 함수다. 이벤트 전후나 대신 실행해 프롬프트를 바꾸고, 도구 호출을 차단·수정·재시도하고, 새 버튼이나 입력 UI를 추가할 수 있으며 CLI와 데스크톱 앱에서 플러그인으로 설치·공유한다.

개발자에게 왜 중요한가

팀이 Claude Code 자체의 동작을 기다리지 않고 작업 방식과 안전장치를 직접 넣을 수 있게 됐다. 예를 들어 CI 상태를 옆 패널에 표시하거나, 운영 설정을 건드리기 전에 추가 확인을 요구하거나, 모든 도구 호출을 감사 로그로 남기는 식의 내부 개발 환경을 만들 수 있다.

직접 써볼 때 알아둘 점

Mods는 샌드박스에서 격리되지 않고 Claude Code와 같은 수준으로 로컬 머신에 접근하므로 출처를 신뢰할 수 있는 것만 설치해야 한다. Team·Enterprise와 관리형 설정 환경에는 위험한 권한 우회를 막는 `sec-default`가 먼저 로드되며, 기존 플러그인 허용·차단 정책도 그대로 적용된다.
