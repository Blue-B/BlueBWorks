구독료를 낸다는 사실과 API 조직에 크레딧이 발급됐다는 사실은 다르다. 금액보다 신청 권한, 연결 조직, 만료일과 Codex 제외 조건을 먼저 확인하도록 구성했다. 실제 계정에 혜택을 신청하거나 유료 API를 호출한 후기는 아니다.

챗지피티 API는 이제 무료인가: 구독과 API 결제는 여전히 별개

챗지피티 구독료를 내면서도 별도로 API 비용을 결제해야 해서 작은 자동화 실험을 미뤘다면 이번 혜택을 확인할 이유가 있다. OpenAI는 10월 28일 UTC 공식 개발자 계정에서 적격 Pro·Business 구독자가 월 최대 500달러의 API 크레딧을 신청할 수 있다고 발표했다. 한국 시간으로는 10월 29일 오전 발표다.

다만 모든 챗지피티 이용자에게 무료 API가 열린다는 뜻은 아니다. 공식 도움말과 개발자 가이드는 대상 구독을 본인이 소유한 API 조직에 연결하는 절차를 요구한다. 구독이 있다고 자동으로 잔액이 들어온 것으로 판단하지 말고, 활성화 이후 실제 크레딧 발급 내역까지 확인해야 한다.

API 조직은 앱과 프로젝트의 사용량·결제를 묶는 계정 단위다. 이 혜택은 그중 연결한 한 조직에 적용되며 챗지피티 대화 횟수나 로그인해서 쓰는 Codex 한도를 늘려 주지 않는다. 기존 구독료와 API 청구 체계도 합쳐지지 않는다. 달라진 것은 구독 혜택으로 별도의 API 비용 일부를 충당할 수 있다는 점이다.

프로 요금제별 금액: 100·200·500달러, Plus는 제외

Pro는 월 100달러 등급에 100달러, 200달러 등급에 200달러, 500달러 등급에 500달러의 전체 결제 기간 기준 API 크레딧을 제공한다. 여기서 달러 금액은 API 사용에 적용되는 크레딧이지 환급금이나 현금 지급액이 아니다. 같은 Pro 이름이어도 가입 등급에 따라 받을 수 있는 금액이 다르다.

공식 문서에 적힌 포함 대상은 Pro 100·200·500과 적격 Business의 유료 Standard·Premium 좌석이다. Plus와 무료 체험은 대상이 아니며, 개발자 가이드는 무료 제공 구독도 제외한다고 명시한다. Enterprise·Edu·기존 Codex 좌석을 이 혜택의 적격 플랜으로 간주할 근거도 없다.

따라서 Plus 이용자가 제목의 최대 금액만 보고 받을 수 있다고 기대하면 안 된다. API를 거의 쓰지 않는 사람이 크레딧 때문에 더 비싼 구독으로 바꾸는 것 역시 별도의 비용 판단이다. 기존 API 지출과 앞으로 실제로 쓸 범위를 비교하는 편이 낫고, 구독 변경이나 결제를 해야만 안내를 읽을 수 있는 것은 아니다.

비즈니스는 좌석 수가 아니라 합산 상한까지 계산해야 한다

Business는 워크스페이스에 있는 각 사람이 500달러씩 받는 구조가 아니다. 월 결제 워크스페이스의 전체 기간 기준 지급액은 유료 Standard 좌석 수에 20달러를 곱한 금액과 Premium 좌석 수에 100달러를 곱한 금액을 더한 뒤, 500달러와 비교해 작은 쪽으로 정한다. 여러 구성원이 조직의 공통 잔액을 쓰는 방식이다.

공식 도움말의 예시대로 Standard 5명과 Premium 3명이면 100달러와 300달러를 더해 월 400달러다. Standard 10명과 Premium 4명이면 계산상 600달러지만 상한 때문에 월 500달러다. 좌석이 늘어도 상한을 넘는 크레딧을 기대할 수 없다는 점이 개인 Pro와 다르다.

연간 요금을 선불로 내는 Business는 일 년치 크레딧을 한 번에 받고 연간 결제 주기당 최대 6,000달러가 적용된다. 중간에 신청한 첫 지급액은 남은 기간에 비례하고 해당 결제 주기가 끝나면 만료된다. 월 지급과 연간 일괄 지급을 섞어서 매달 500달러에 연간 6,000달러가 추가로 붙는 것으로 계산하면 안 된다.

무료 크레딧 받는 법: 7일 조건과 소유자 권한부터

신청 전에는 세 가지를 먼저 본다. 유료 적격 구독이 최소 7일 동안 활성 상태였는지, 연결에 쓰는 ChatGPT 계정과 API 계정의 이메일이 같은지, 신청자가 구독 또는 Business 워크스페이스와 수신 API 조직 모두의 소유자인지다. Business 멤버나 관리자 역할만 있는 것으로는 충분하지 않다. API 조직의 결제 관리 권한도 확인해야 한다.

ChatGPT에서 시작한다면 해당 구독 소유 계정으로 로그인하고, Pro는 설정의 Billing으로 들어간다. Business는 대상 워크스페이스를 고른 다음 워크스페이스 결제 설정이나 Admin Console을 연다. API credits 혜택을 찾아 연결 절차를 시작하고, 크레딧을 받을 조직을 검토한 뒤 확정한다. API Platform의 Billing에서 시작하는 경로도 같은 혜택을 연결한다.

조직이 여러 개라면 실제로 앱을 실행할 조직을 선택하는 부분이 중요하다. 한 적격 구독 또는 워크스페이스는 한 API 조직에만 연결되고, API 조직도 이런 활성 연결 하나만 가질 수 있다. 이미 연결된 조직을 바꾸려면 지원팀에 문의해야 하며, 변경 요청이 크레딧 이전이나 추가 지급을 보장하지 않는다. 먼저 확인할 수 있는 선택을 건너뛰고 반복 신청하는 방법을 권할 이유가 없다.

API를 처음 쓰는 경우에도 같은 이메일의 Personal API Organization에 연결할 수 있으며 ChatGPT 쪽 신청 전에 API 온보딩을 모두 끝낼 필요는 없다고 도움말은 설명한다. 다만 메뉴가 보이지 않으면 플랜·구독 기간·선택한 워크스페이스·이메일부터 확인해야 한다. 국가와 활성화 대상 그룹에 따라서도 제공 여부가 달라질 수 있으므로 한국의 모든 계정에 즉시 보인다고 단정할 수는 없다.

사용법과 만료일: 연결 성공 뒤 Credit grants를 확인한다

활성화한 뒤에는 API Platform에서 연결한 조직을 선택하고 결제 개요와 Credit grants를 확인한다. 받은 금액과 만료일이 실제로 표시되는지 보는 단계다. 사용량 보고서는 사용한 API의 비용을 보여 주지만 크레딧 적용 후 현금으로 청구된 금액과 반드시 같지는 않다. 연결 상태, 지급 기록, 사용 기록을 나눠 보면 잔액이 안 보이는 문제를 구분하기 쉽다.

첫 지급액은 현재 유료 결제 기간에서 남은 시간만큼 일할 계산된다. 예를 들어 전체 기간 금액이 200달러여도 중간에 신청하면 처음부터 200달러가 온다고 보장할 수 없다. 구체적인 계산 결과는 신청 화면에 나타난 금액으로 확인해야 한다. 이 글은 실제 계정에서 혜택을 수령한 사용기가 아니라 공식 문서를 바탕으로 한 절차 안내다.

이후에는 혜택이 유지되고 구독 자격이 계속 충족되는 동안 갱신 시 자동으로 지급되므로 매번 다시 신청할 필요는 없다. 월 크레딧은 구독 결제 주기 끝에 만료되고 남은 금액은 이월되지 않는다. 연 선불 Business도 연간 결제 주기 끝에 남은 금액이 만료된다. 오늘 받은 잔액을 몇 달 모아 큰 작업에 쓸 수 있는 적립금으로 생각하면 안 된다.

어디에 쓸 수 있나: 앱 API와 Codex 한도는 다르다

개발자 가이드는 연결 조직으로 청구되는 Responses, Agents, Decisions, GPT-Live·Realtime, Images와 내장 도구 비용을 포함한다고 설명한다. Agents의 OpenAI 호스팅 샌드박스 비용, 웹 검색·파일 검색·Code Interpreter와 관련 사용량·저장 비용도 적용 범위에 들어간다. 크레딧이 모델의 텍스트 출력에만 쓰이는 것은 아니다.

반대로 API 키로 사용하는 Codex는 이 혜택이 지원하지 않는다고 두 공식 문서가 명시한다. 로그인한 Codex나 ChatGPT 사용량 제한도 늘어나지 않는다. 따라서 코딩 에이전트를 오래 돌리려고 신청한다면 어떤 제품과 어떤 인증 경로로 청구되는지를 먼저 구분해야 한다. API 크레딧을 받았다는 이유만으로 기존 Codex 사용 한도가 초기화되지는 않는다.

Business 팀원에게도 접근 권한은 별개다. ChatGPT 좌석을 가진 사람에게 API 조직이나 프로젝트 권한이 자동으로 생기지 않으므로, 팀 앱에서 쓰려면 해당 조직과 프로젝트 접근을 따로 구성해야 한다. 요청에는 연결 조직에 속한 프로젝트의 API 키를 사용한다. 키 자체는 공개 코드나 브라우저 화면에 넣지 않고 서버 쪽 비공개 환경에서 관리하는 편이 안전하다.

크레딧을 다 쓰면 유료로 넘어가나: 기존 잔액과 자동 충전 확인

활성 프로모션 크레딧을 쓰는 데 API 결제수단을 새로 등록할 필요는 없다. 다만 기존에 구매한 API 크레딧이 있다면 무료 잔액이 먼저 사용되고, 소진 뒤에는 구매 잔액을 계속 사용한다. 무료 몫이 끝나면 언제나 모든 요청이 멈춘다는 설명은 이미 유료 잔액이 있는 조직에는 맞지 않는다.

남은 크레딧이 전혀 없으면 요청이 HTTP 429와 credit_balance_exhausted 오류로 실패한다고 공식 문서에 적혀 있다. 그러나 429라는 상태 코드만 보고 곧바로 돈이 부족하다고 단정해서도 안 된다. 요청 속도나 토큰 한도는 크레딧과 별개이고 잔액이 있어도 제한될 수 있다. 정확한 오류 코드와 선택한 조직·프로젝트부터 보는 편이 낫다.

처음 실험할 때는 작업별 사용량과 만료일을 함께 기록해 두는 것이 유용하다. 자동 충전이 설정돼 있다면 충전 기준·목표 잔액·월 구매 한도를 확인해야 한다. 여기서 안내하는 신청 절차는 결제수단 등록이나 Auto Recharge 활성화를 요구하는 작업이 아니다. 이 글을 위해 실제 계정의 구독·결제·충전 설정을 바꾸지는 않았다.

자주 묻는 질문: Plus 대상, 첫 금액, Codex와 자동 지급

결론적으로 기존 Pro·Business 구독자가 앱이나 API 자동화를 시험할 때는 확인할 가치가 있는 혜택이다. 다만 최대 금액 하나로 구독 변경을 결정하기보다 현재 플랜의 자격, 실제 연결 조직, 지급액과 만료일, 쓰려는 제품의 적용 여부를 순서대로 확인하는 편이 실용적이다. 다음 질문도 2026년 10월 30일 공식 문서 확인 기준이며 혜택은 향후 바뀌거나 종료될 수 있다.

ChatGPT Plus도 API 무료 크레딧을 받을 수 있나요?

아니요. 본 혜택의 포함 플랜은 유료 Pro 100·200·500과 적격 Business의 유료 Standard·Premium 좌석입니다. Plus와 무료 체험은 대상이 아닙니다.

월 200달러 Pro면 처음부터 API 200달러가 지급되나요?

전체 월 결제 기간 기준 금액은 200달러지만 첫 지급은 남은 유료 결제 기간에 비례합니다. 신청 화면의 금액과 API Credit grants의 실제 발급액·만료일을 확인해야 합니다.

이 크레딧으로 Codex를 더 오래 쓸 수 있나요?

API 키를 통한 Codex 사용은 혜택에서 제외되고, 로그인한 Codex나 ChatGPT의 사용량 한도도 늘어나지 않습니다. 연결 API 조직의 지원 API 사용에 적용되는 크레딧입니다.

매달 다시 신청해야 하나요?

한 번 활성화한 뒤에는 혜택이 유지되고 적격 구독이 계속되는 동안 갱신 시 자동 지급됩니다. 남은 월 크레딧은 이월되지 않고 해당 결제 주기 끝에 만료됩니다.
