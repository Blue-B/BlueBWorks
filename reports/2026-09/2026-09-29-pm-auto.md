# 2026-09-29 PM — TransitionGuard

## 선정

짧게 비교한 후보:
1. **TransitionGuard** — React 19.3에서 안정화된 View Transition 도입 시 정적 이름 충돌과 사용 위치를 로컬에서 빠르게 확인. 작게 완성 가능하고 브라우저 오류를 사전에 줄일 수 있어 선택.
2. **SkillFence** — 공유 Agent Skills의 외부 지시 링크를 사전 검토하는 도구. 의미는 있지만 기존 AgentScope와 주제 축이 가까워 이번 회차에서는 제외.
3. **CodexHostProbe** — WSL/호스트 실행 차이를 진단하는 환경 점검기. 특정 도구·버전에 너무 종속돼 제외.

## 근거

- React 19.3: https://react.dev/blog/2026/09/09/react-19-3 — 2026-09-29 확인, 2026-09-09 발표.
- MDN view-transition-name: https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/view-transition-name — 2026-09-29 확인.
- MDN view-transition-class: https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/view-transition-class — 2026-09-29 확인.

대안:
- Stylelint: https://stylelint.io/ — 범용 CSS 린터. TransitionGuard는 별도 규칙 작성 없이 View Transition 이름/클래스와 React 사용을 함께 요약.
- ESLint: https://eslint.org/docs/latest/ — JS/TS 중심. CSS의 view-transition-name과 React 사용을 함께 보지 않음.
