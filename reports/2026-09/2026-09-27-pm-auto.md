## 프로젝트

AgentScope — 저장소 안의 AI 코딩 에이전트 지침 파일을 읽어 특정 코드 경로에 어떤 지침이 적용되는지 우선순위대로 보여주는 오프라인 Python CLI.

## 선정 근거

후보 세 개를 짧게 비교했다.

1. **AgentScope** — GitHub Copilot은 저장소 전체·경로별·agent instructions를 함께 지원하고, Codex도 2026년 7월 `AGENTS.md` 기반 코드 리뷰 규칙을 공개했다. 여러 에이전트 지침이 섞인 저장소에서 실제 적용 범위를 실행 전에 확인하는 작은 도구로 완결할 수 있어 선택했다.
2. **OpenAPI 3.2 변경 사전점검** — 최근 규격 변화는 분명하지만 oasdiff 등 성숙한 diff 도구가 이미 있어 이번 규모에서 차별점이 약했다.
3. **환경변수 계약 드리프트 점검** — 실용적이지만 최근 에이전트 지침 형식 분화에 비해 이번 회차의 시의성이 낮았다.

확인한 자료:
- GitHub Copilot custom instructions: https://docs.github.com/en/copilot/concepts/prompting/response-customization
- OpenAI Codex custom code review rules, 2026-07-20: https://developers.openai.com/ko-KR/blog/custom-code-review-rules-for-codex
- OpenAPI 3.2 소개: https://www.openapis.org/blog/2025/09/23/openapi-specification-v3-2-0-released

대안과 차이:
- **GitHub Copilot instruction references**는 Copilot 실행 흐름 안에서 실제 사용된 지침을 확인하는 데 유용하다. AgentScope는 세션을 시작하기 전에 로컬 파일만 읽어 범위를 확인한다.
- **rulesync**(https://github.com/dyoshikawa/rulesync)는 여러 에이전트 규칙 형식을 동기화·변환한다. AgentScope는 파일을 수정하지 않는 읽기 전용 범위 점검이다.
