# 2026-09-26 오전 — ScopeDiff 수동 시험

상태: 로컬 프로토타입 구현·검증 완료. 원격 CI 확인 보류. 무인 예약 실행 성공으로 세지 않는다.

## 선정

MCP 업데이트 전후의 도구 선언과 입력 규격 변화를 로컬에서 검토한다. 개인 개발자·유지보수자가 도구 목록 두 개를 넣으면 추가·삭제·설명·힌트·필수 입력 변화를 확인할 수 있다. 실제 권한 또는 보안 판정 도구는 아니다.

조사 후보 세 개(모두 2026-09-26 확인):

1. **MCP 도구 선언 변경 검토** — 선정. 공식 문서에 명시된 힌트와 목록 변경을 실제 사용자 입력으로 비교할 수 있고, 서버 실행·외부 전송 없이 완결된 작은 도구로 구현 가능하다. 수요는 검증 전이다. https://blog.modelcontextprotocol.io/posts/2026-03-16-tool-annotations/ 및 https://modelcontextprotocol.io/specification/2026-07-28/server/tools
2. **터치 대상 크기 점검** — 보류. W3C의 작은 버튼·간격 문제는 명확하지만 실제 페이지 검사와 예외 처리 범위가 커진다. https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum
3. **배경 탭 복귀 점검** — 보류. 실제 OS 절전과 브라우저 수명주기의 재현·검증이 더 필요하다. Chrome 57 문서를 현재 모든 브라우저의 상세 정책으로 일반화하지 않는다. https://developer.chrome.com/blog/background_tabs

MCP Inspector는 서버 접속·호출 시험, Snyk Agent Scan은 구성 발견·보안 분석에 초점을 둔다. ScopeDiff는 확보한 두 목록의 선언 변화만 오프라인에서 검토한다. 상세 비교와 출처는 projects/scopediff/README.md 및 project.json에 기록했다.

## 실제 산출물

- 도구 목록 붙여넣기, JSON 파일 선택·끌어놓기, 여러 서버 목록.
- 추가·변경·삭제·동일 분류, 검색·필터, 원문 비교, 미선언 기본값 표시.
- JSON/Markdown 보고서 다운로드, Node CLI, 의존성 없는 단일 HTML 빌드.
- 가상 예제임을 표시하며 실제 사용자 파일도 같은 경로로 처리.
- 브라우저 네트워크 연결·영구 저장·실제 도구 실행 없음.

## 실행한 검증

- 저장소 검사기 원본의 Git blob 해시를 대조한 뒤 회귀 테스트 26개 실행: 모두 통과.
- python3 automation/check.py: 프로젝트 등록 검사 통과.
- python3 automation/check.py --run: 비교·입력 오류·CLI·빌드 회귀 테스트 63개, 단일 HTML 빌드, CLI 진입 검사 모두 정상.
- Chromium 144 오프라인 브라우저 시나리오 15개 통과: 실제 파일 입력, 끌어놓기, 검색·필터, 두 보고서 다운로드, 오류 처리, 악성 HTML의 텍스트 표시, 390px/320px 가로 넘침 없음.
- 브라우저 테스트 중 JavaScript 오류·CSP 오류·네트워크 요청 모두 0건.
- HTML 빌드 시 문자열 치환이 소스의 `$&`를 변형하던 문제를 수정하고 실제 바이트·CSP 해시 회귀 검사를 추가했다.
- 스키마 정규화가 기본값·예제·메타데이터의 배열까지 정렬하던 문제를 수정했다. 검사를 약화하지 않고 별도 회귀 테스트를 추가했다.
- 등록 검사에서 지원하지 않는 CSS 확장자를 필수 코드 목록에 넣은 오류를 수정했다. CSS 파일은 유지하며 빌드 회귀 검사에서 검증한다. 저장소 검사기나 CI 설정은 변경하지 않았다.

## 확인하지 못한 부분과 실행 환경 장애

Oracle ARM DevSpace와 일반 DevSpace는 작업공간 열기 이후 실행 요청에서 `workspace_id: expected string, received undefined`로 실패했다. 공개된 호출 스키마는 workspaceId를 요구했다. 원격 서버에서 실행했다고 주장하지 않으며 ChatGPT의 별도 실행 환경에서 검증했다.

GitHub Actions 실행 https://github.com/Blue-B/BlueBWorks/actions/runs/36190710298 는 테스트 단계 시작 전 실패했고 steps는 빈 배열, runner_id는 0이었다. 로그 조회도 BlobNotFound로 실패했다. 원인·과금 문제를 단정하지 않고 CI 성공으로 표시하지 않는다. 결제·권한·공개 범위·워크플로 설정은 바꾸지 않았다.

테스트 환경에서 file://와 로컬 HTTP 탐색은 관리자 정책으로 차단됐다. 빌드한 HTML을 CSP 변경 없이 Chromium 문서에 직접 로드(set_content)해 오프라인으로 검사했다. 실제 더블클릭 경로, 모바일 실기기, Safari·Firefox는 미검증이다.
