# 2026-09-26 오전 — ScopeDiff 수동 시험 회차

상태: 구현 반영, 검증 진행 중. 아직 완료 회차로 세지 않는다.

## 선택한 문제

MCP 업데이트 전후에 모델에 노출되는 도구의 이름·설명·힌트·입력 규격이 바뀌는 문제를, 서버에 다시 접속하거나 실행하지 않고 검토한다. 타깃은 MCP를 사용하는 개인 개발자와 유지보수자다.

## 조사한 후보

1. **MCP 도구 선언 변경 검토** — 선정. 읽기 전용 선언 해제, 외부 상호작용 범위, 필수 입력 변경을 실제 tools/list 입력으로 검토할 수 있다. 공식 2026-03-16 글과 2026-07-28 규격을 근거로 삼았다. 수요와 상업성은 검증 전이다.
2. **터치 대상 크기 점검** — 보류. W3C WCAG 2.2의 작은 버튼과 간격 문제는 명확하지만 정확한 실제 페이지 검사를 위해 브라우저 확장·예외 처리 범위가 더 커진다. https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum (2026-09-26 확인)
3. **백그라운드 탭 복귀 점검** — 보류. Chrome이 배경 작업을 제한한다는 공식 문서로 문제는 확인했으나 실제 OS 절전·브라우저 수명주기 재현까지 단일 회차에서 검증하기 어렵다. 오래된 Chrome 57 문서를 현재의 모든 세부 정책으로 일반화하지 않는다. https://developer.chrome.com/blog/background_tabs (2026-09-26 확인)

## 구현 범위

- 두 tools/list JSON 목록, JSON 파일, 여러 서버 묶음 비교.
- 추가·삭제·변경·동일 분류, 검색, 확인 필요 필터.
- 힌트 변경과 미선언 기본값을 구분. 스키마 필수값·타입·열거값 변화 및 설명 변화 표시.
- 원문 비교와 JSON/Markdown 보고서. 네트워크 연결·도구 실행·브라우저 영구 저장 없음.
- 의존성 없는 Node CLI와 단일 HTML 빌드.
- 예제는 가상 데이터로 명시하며 실제 입력 경로를 함께 제공.

## 환경 문제

Oracle ARM DevSpace와 일반 DevSpace 모두 workspace 열기는 성공했으나 bash 호출이 `workspace_id: expected string, received undefined`로 실패했다. 공개된 도구 스키마는 workspaceId를 요구하는데 실행 서버가 다른 필드명을 기대하는 상태다. 권한을 우회하지 않고, ChatGPT 실행 환경과 GitHub 연결 도구로 대체 검증한다. 원격 서버에서 실행했다고 주장하지 않는다.

## 비교 대상과 출처

MCP Inspector: 서버 접속·호출 시험. Snyk Agent Scan: 에이전트 구성 발견·보안 분석. ScopeDiff: 확보된 두 목록의 선언 변경 검토로 범위를 제한. 자세한 출처 및 차이는 프로젝트 README와 project.json에 기록했다.
