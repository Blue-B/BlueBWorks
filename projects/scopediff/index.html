어떤 데이터를 넣으면 돼?

MCP Inspector 등에서 확인한 tools/list의 전체 JSON 응답을 사용해. {"tools":[...]}, {"jsonrpc":"2.0","result":{"tools":[...]}}, 도구 배열을 지원해. 여러 서버는 {"servers":[{"name":"서버 이름","tools":[...]}]}으로 묶어줘.

각 도구에는 name과 inputSchema가 필요해. 연결 주소·API 키가 들어 있는 mcpServers 설정 파일은 받지 않아. 페이지가 남았다는 nextCursor가 있으면 비교를 멈춰. 내보낸 보고서에는 도구 원문이 포함될 수 있으니 공유 전에 확인해.

힌트는 서버의 자기 선언이야. 실제 권한·동작·안전성이나 완전한 스키마 호환성을 보장하지 않아.
