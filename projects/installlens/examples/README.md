# Illustrative input only

These files are small synthetic inspection fixtures, not an installable npm project. Names, versions, URLs, and integrity values are illustrative. Do not run npm install here. They do not assert anything about real registry packages.

The lockfile has five package entries: one install script, one Git source, one remote URL, and one registry entry without integrity. The optional package.json marks the exact sample script version approved. InstallLens reads the files only; it never contacts these URLs or installs anything.
